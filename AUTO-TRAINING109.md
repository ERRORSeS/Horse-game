# Automatic training and mixed calendar formats

Automatic scheduled lessons now run despite ordinary readiness blockers: fatigue/daily stamina, overlapping activity spans, weather, missing tack, medical-work preferences and untreated conditions. A living horse with an enabled automatic work day receives a real lesson using the existing warm-up, attempt, gain and reporting pipeline. Young, unbroken or retired horses receive groundwork/light work rather than being skipped. Missing/incompatible saved exercises fall back to groundwork. Rest/turnout days and manually scheduled lessons retain their intended behavior.

An unresolved condition with an active rehabilitation/treatment plan or hospital care pauses automatic training. Known symptoms or an untreated injury alone do not count as active treatment. Completing/resolving the relevant treatment lets future scheduled sessions resume. The policy does not erase conditions, assessments or history. The existing engine still determines actual exercise outcomes and gains; it does not award guaranteed progress for failed work. Each scheduled hour is processed once, with the existing scheduled-hour mood seed. Manual training and competition rules are unchanged.

Calendar classes now have a stable mixture of single-round and jump-off formats rather than making every generated standard/recognized individual class a jump-off. The deterministic default targets roughly 55% jump-offs; a 100-definition check produced 61 jump-off and 39 single-round classes. Explicit class choices, team/schooling defaults, Puissance, entered classes and completed results are retained. Unentered future generated classes pick up the mixed defaults on load.

Native browser checks passed: real progress through fatigue, exhausted stamina, a busy activity span, storm weather, missing equipment, pending assessment and an untreated strain; no duplicate scheduled-hour processing; active treatment pauses; completion/resolution resumes; preserved medical records; saved history; an actual day skip runs the automatic lesson. Calendar format mixture/stability and the calendar/jump-off browser regression passed. Training report chronology and rider-action regressions passed. The full historical suite was not run.

Run `npm run test:auto-training-policy-browser` with a static server on port 8121 or set GAME_URL. Existing visual layout is retained; the weekly schedule includes a short explanation of the automatic-training rule.
