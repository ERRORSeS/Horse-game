Reduce Lag setting

Settings now includes a saved Reduce Lag: ON/OFF button, defaulting to ON for both existing saves without a preference and new careers.

ON schedules only categories the player's rider profiles qualify for, using the same age, nationality, division and owned-horse-age logic as active ranking pools. Opening an unrelated ranking board does not activate its calendar simulation. Category eligibility is evaluated at each event's date, so age transitions change the active categories automatically. All eligible profiles count, rather than only the currently selected rider.

OFF schedules every available category, including categories the player does not qualify for or has not viewed. Separate country pools remain separate. Both modes retain the existing per-category 50 inactive / 100 active NPC limits and gradual growth on entry.

This setting filters background event schedules only. It does not lower opponent skills, change the field-selection engine, cut eligible competition fields, alter fault difficulty, change scoring, delete earned points or replace opponents. A real result may still credit multiple related boards under the ordinary scoring rules. Unrelated categories resume at future scheduled events when reduction is disabled; paused time is not backfilled. Explicit Background NPC Simulation pause remains respected. Optional rider career progression remains a separate preference.

Verification

Native browser checks cover the actual settings button and both saved states across reloads; reduced schedules contain every eligible class and no unrelated class; resuming all categories produces unrelated real meets without replaying paused time; all created pools respect their 50/100 caps. A compared class retained identical 33 NPC rider/horse/strength tuples in both modes. In the sample month, filtering reduced 62 scheduled classes to 2 relevant classes. This demonstrates reduced simulation work, not a guarantee for every save or device.
