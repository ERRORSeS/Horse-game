# Oxer to Oxer 8.2

## National teams

Open **Calendar → National team applications**. Career progression and the National Team Applications setting enable the system. A rider needs a recorded age and sporting nationality, a suitable horse, and a recent verified regional-or-higher top-ten result in the division. Applications are recorded by rider, horse, country, discipline, division, and season.

The fictional season closes applications in month 3, reviews and shortlists applicants, holds selection trials in month 5, and announces the squad in month 6. Recorded performances can generate development or national-squad invitations during the application window. Invited riders can enter their trial through the calendar. Player and NPC candidates are evaluated against results, consistency, horse readiness, rider skill, ranking, and current form. Score ties use recorded evidence and stable rider IDs. The first five candidates may receive development, national, or championship membership, and the next eligible candidate may be named reserve. Squad decisions, reserve positions, and application history persist across reloads.

Team and Games entries in this mode require an active nomination for the combination, followed by the existing championship and horse checks. Team results use the existing class-specific starter and counting-score rules. Selection does not grant points or horse value by itself.

## Calendar

The shared shop-style calendar provides monthly, season-list, annual-major, and 2026 reference views. The same controls sort actual prestige, date, class tier, purse, deadline, region, and suitability. Filters combine discipline, division, level, special class type, prestige range, and entry status with the selected rider and horse. Earlier calendar tools and reminders are in the matching stable tools drawer.

The 2026 reference view uses 16 published event windows with organizer links. These include the five League of Nations dates, Dutch Masters, Saut Hermès, Fort Worth finals, Kentucky, Badminton, Luhmühlen, Aachen, Spruce Meadows, the Asian Games equestrian programme, Riyadh, and Geneva. Kentucky uses the organizer's April 23–26 competition window. Real reference dates use the Gregorian calendar and are separate from playable fixtures. Fictional seasons use stable dates on the 30-day game calendar. World championships and Games follow their configured four-year cycles.

## Custom shows

Use **Calendar → Create custom show** to set a title, venue, country, date, duration, weather, prestige, and up to 12 classes. Classes support discipline, game level, rider division, pony and young horse restrictions, format, jump-off, supported special tests and eventing formats, field capacity, NPC participation, and purse. Sandbox shows can repeat annually. Their results are saved separately and their displayed purses are simulated.

Career recognition is a rule-based approval for local-to-national classes. It requires prior organizer results, an existing venue, a suitable field, standard rules, and prize funding. Approved classes can award national points when their actual field qualifies. The existing scoring and travel systems run both modes, and the custom record saves entries and awards by edition and class.

## Hackamore equipment

The legacy save loader used to fill a missing bit slot with the default Loose Ring Snaffle even when the bridle was bitless. The loader now preserves the empty slot for bitless bridles and respects explicitly unequipped bits. Compatibility and active equipment resolution use the catalogue's bit category. An actual separate bit still produces a warning that names the item. A valid inventory item stays available after it is unequipped.

## Verification and scope

Automated checks cover hackamore reloads, inventory references, real conflicts, applications, milestone selection, ranking isolation, sandbox awards, recurring IDs, prestige sorting, and championship cycles. Chromium checks cover the annual view, the 16 reference cards, creation of a two-class show, and the 390 px layout.

The custom creator uses existing technical levels and judging engines. Each saved class supports one player booking. Published real schedules are an optional reference view. The playable programme uses fictional events and game rules.
