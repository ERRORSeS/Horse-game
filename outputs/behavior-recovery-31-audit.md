# Rider Realism 3.1 validation

The existing training and competition engines own outcomes. Staff dialogue no longer forces cooldown or blocks the next interactive attempt. Explicit End Session, falls, medical eligibility, weather restrictions, elimination and finished-session checks remain in their existing paths. Selected misconduct records its concern once and grants no bonus.

Resolved experiences own learned changes. Ordinary partial execution without a real conflict does not cause decline. Significant difficulties change relevant confidence by 2–3 points; recurring unresolved difficulties by 3–5, within eight-point per-stat session/day limits. Contact trust/collection effects retain the existing four-point ordinary session caps. Natural temperament, technical skills, genetics, Bond and QOL are separate.

The learning journal records horse, rider identity, exercise/context, date, session, and actual before/after values. Aid consequences are merged into the matching resolved training record. Calendar advancement has no behavioral learning hook. Quick competition learning uses actual result text/fields, and RPG learning uses the resolved main-round outcome, rather than the rider's skill or choice quality.

Recovery sessions are counted only when an actual relevant positive outcome has improved a learned value and the training session is completed. The latest contextual setback starts a new recovery sequence. A three-session milestone is awarded once; unfinished, failed and repeated finish calls cannot qualify. Old imported narrative history is not treated as evidence of newly verified recovery sessions.

All eighteen supplied quotes are retained behind explicit predicates. The journal can state that a difficulty remains unresolved or show the actual Jump Confidence without changing it. Existing recovery language also requires verified improvement; multi-session language requires three completed relevant positive sessions. A menu, rest, a follow-up choice or a new rider alone cannot prove recovery.

The lesson panel now keeps the latest actual exercise outcome and all associated observations, instead of truncating them to three rows. When no separate aid event occurred, it displays the selected aid or that no optional aid was selected. Last Attempt Calculations reads the actual outcome's probability record.

New regression groups cover staff/player decisions, contextual decline and protected values, failed/partial sessions, three-session completion and one-time milestones, real idle hour/day/month advancement, outcome/behavior/aid visibility, save/import idempotence, mounted interactive/quick/automatic training, all eighteen quote predicates, and a real negative attempt's final journal values. Existing rider-realism tests now assert that unsupported recovery claims are suppressed and that real auto/quick attempts remain individually identifiable.

Final validation (2026-11-03): complete `npm test` exited 0, including ten new 3.1 regression groups, all existing rider/tack regressions, competition scoring, saved-state checks, auto training and time-skip performance checks. Browser checks loaded the existing saved three-horse stable, resumed mounted flatwork, resolved partial and clean outcomes, reloaded the session, and verified visible Outcome, Behavior and Aids/Equipment observations with no warning/error console entries.
